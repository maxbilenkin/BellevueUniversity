# DSC 530 – Data Exploration and Analysis

## Course Overview
This course focuses on advanced techniques for **profiling, exploring, and understanding data**. Students apply programming and statistical inference to ask and answer insightful questions. Exploratory Data Analysis (EDA), visualization, and interpretation of results are emphasized. Prerequisites: DSC 510 and DSC 520.

## Course Project
For the project, I analyzed **factors influencing loan approval** using Python and Jupyter Notebook. The goal was to identify key variables that affect approval decisions and provide actionable insights.

### Project Focus
- Assessing the impact of applicant income, loan amount, credit score, and employment experience on loan approval
- Investigating correlations, patterns, and relationships among variables
- Identifying practical insights for borrowers and lenders

### Dataset
- Kaggle dataset containing **44,972 loan applications**
- Pre-processed to remove extreme outliers and improve analysis accuracy

### Techniques & Tools
- **Python & Jupyter Notebook**
- Data cleaning and preprocessing
- Descriptive statistics and distributions
- Probability Mass Function (PMF) & Cumulative Distribution Function (CDF) analysis
- Correlation analysis and hypothesis testing
- Regression analysis

### Visualizations
- Bar charts and categorical plots
- Histograms of numerical features
- Correlation matrix heatmaps
- Scatter plots with log scales
- Boxplots and CDF charts
- Pairplots with correlation coefficients

### Key Insights
- **Loan-to-income ratio** strongly affects loan approval probability
- **Income** and **loan amount** are moderately correlated, but income alone is not the most significant factor
- **Employment experience** and **credit score** show weak or no significant correlation with approval
- Visualizations reveal trends, distributions, and relationships that help interpret data and inform decision-making
- Limitations: Correlation does not imply causation; additional factors such as lender policies and debt-to-income ratio may influence outcomes
