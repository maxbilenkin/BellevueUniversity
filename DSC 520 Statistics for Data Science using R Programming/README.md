# DSC 520 – Statistics for Data Science

## Course Overview
This course introduces the **R programming language** for statistical analysis and data exploration. Students learn to perform statistical tests, manipulate datasets, and present results in a clear, report-ready format. Report writing and data visualization are emphasized.

## Course Project
For the final project, I analyzed the impact of **excessive alcohol consumption on health and society**. The goal was to identify patterns, correlations, and predictors using real-world datasets.

### Project Focus
- Understanding the health and societal effects of excessive alcohol consumption
- Investigating environmental, genetic, and policy factors
- Exploring correlations with happiness and life expectancy
- Generating actionable insights and recommendations

### Datasets Used
1. **Global Alcohol Consumption by WHO** – 1960–2020, 48,924 records per capita alcohol consumption (grams)  
   [WHO data link](https://www.who.int/data/gho/data/themes/topics/topicdetails/GHO/levels-of-consumption)
2. **Alcohol and Life Expectancy (Kaggle)** – International dataset linking alcohol consumption to life expectancy  
   [Kaggle link](https://www.kaggle.com/datasets/thedevastator/relationship-between-alcohol-consumption-and-lif/data)
3. **Happiness and Alcohol Consumption (Kaggle)** – Survey-based dataset to analyze correlation between happiness and alcohol use  
   [Kaggle link](https://www.kaggle.com/datasets/marcospessotto/happiness-and-alcohol-consumption)

### Tools and Packages
- **RStudio**
- **R packages:** SNPassos, genetics, GA, dplyr, ggplot2, caret, tidyverse
- Data visualization: Manhattan Plot, Q-Q Plot, Heatmap, Boxplot, ROC Curve

### Skills Demonstrated
- Data cleaning, transformation, and manipulation in R
- Statistical testing and exploratory data analysis
- Visualizing complex data patterns
- Applying insights to public health questions
- Integrating multiple datasets to answer research questions
