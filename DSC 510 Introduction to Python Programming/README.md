# DSC 510 – Introduction to Programming

## Course Overview
This course introduces the Python programming language as a tool for cleaning, processing, and analyzing datasets. It also covers fundamental programming concepts and techniques for configuring a computer environment for data science work.

## Technologies Used
- Python
- PyCharm
- REST APIs
- JSON data handling

## Course Project
For the final project, I developed a Python application that retrieves real-time weather information using the **OpenWeather API**.

The program allows users to enter either:
- a **ZIP code**, or  
- a **city and state**

The application then sends a request to the OpenWeather API and returns current weather information for the specified location.

## Key Features
- User input validation for location queries
- API request handling
- Parsing JSON responses from the API
- Displaying weather data in a readable format

## Skills Demonstrated
- Python programming fundamentals
- Working with external APIs
- Handling JSON data
- Building command-line applications
- Structuring Python programs
