# DSC 550 – Data Mining and Machine Learning

## Course Overview
This course covers importing, cleaning, manipulating, visualizing, analyzing, and modeling structured and unstructured data to uncover patterns and anomalies. Topics include text sentiment analysis, regression, classification, neural networks, feature dimensionality reduction, and model hyperparameter tuning. Knowledge from this course culminates in a comprehensive term project.

## Project: Finding Patterns in Credit Card Transactions to Detect Fraud

### Project Description
Credit card usage has become essential, but fraudulent transactions are a growing problem. The goal of this project is to detect fraudulent transactions using historical credit card transaction data. By leveraging machine learning and statistical analysis, patterns indicative of fraud can be identified to minimize financial losses for banks and improve security for consumers and merchants.

### Tools & Techniques Used
- **Python** for data cleaning, analysis, and visualization  
- **Pandas, NumPy, Matplotlib, Seaborn** for data manipulation and plotting  
- **Exploratory Data Analysis (EDA)** to detect patterns and anomalies  
- **Machine Learning Concepts**: classification models to predict fraud risk  

### Key Visualizations
- Fraud vs. Non-Fraud Transactions Count (Bar Chart)  
- Transaction Amounts by Fraud vs Non-Fraud (Box Plot)  
- Category-wise Distribution of Transactions (Fraud vs Non-Fraud)  
- Gender Distribution in Fraud vs Non-Fraud Transactions (Categorical Bar Chart)  

### Impact & Insights
- Identified transaction patterns that are indicative of fraud  
- Highlighted the importance of features like transaction amount, category, and gender in predicting fraudulent activity  
- Demonstrated how machine learning models can proactively support fraud prevention
